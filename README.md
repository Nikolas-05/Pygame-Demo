# Pygame-Demo
Lightning talk demo
For our demo, we aim to display some key Pygame features such as collision detection, key.get.pressed movement, and image importing. Our game is our take on the popular "Galaga" game. You, "the player," will be dodging and destroying enemies. As time progresses, the speed will increase, increasing the difficulty.
